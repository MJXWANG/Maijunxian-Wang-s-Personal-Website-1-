# Maijunxian (Mark) Wang — Personal Website

Academic homepage for Maijunxian (Mark) Wang, undergraduate researcher in Cognitive
Science at UC Berkeley. Single static page served via GitHub Pages.

**Live:** https://mjxwang.github.io/Maijunxian-Wang-s-Personal-Website-1-/

## Contents

| File | Purpose |
|------|---------|
| `index.html` | The site — bilingual (EN / 中文), dark-mode toggle, no build step |
| `Maijunxian_Wang.jpg` | Profile photo |
| `Maijunxian_Wang_CV.pdf` | Downloadable CV (kept in sync with the `markcv` source) |
| `archive/` | Retired assets (dated subfolders) |

## Structure

`index.html` is self-contained (inline CSS/JS, Google Fonts). Sections: Hero + links,
News, Selected Publications, Research Interests — mirrored in English and Chinese.

To update publications/news, edit the matching `<li>` in **both** the `#content-en`
and `#content-cn` blocks.
